# Security Policy

## Supported Versions

Security fixes are currently provided for the latest version available on the
default branch.

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |
| Older   | No        |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you discover a security vulnerability in SchemaBridge, please report it
privately through the repository's GitHub Security Advisories.

Include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected component or version
- The potential impact
- Any suggested mitigation, if available

Please allow reasonable time for investigation and remediation before publicly
disclosing the vulnerability.

## Scope

Security reports may include vulnerabilities affecting:

- SchemaBridge CLI
- Schema analysis and inference
- Contract translation
- Web application
- VS Code extension
- Chromium extension
- Backend services
- Dependency or build configuration

## Sensitive Data

Do not include API keys, credentials, access tokens, private contracts,
customer data, or other sensitive information in public issues or pull
requests.
